## 🚀 Proyectos destacados

### 🎫 [LiganTicket API](https://github.com/CarlosBecharaDev/LiganTicket-API)
API REST para gestión de filas y turnos de atención (bancos, hospitales, EPS).
- Autenticación y autorización con **Spring Security + JWT**, control de acceso por roles con `@PreAuthorize`
- Arquitectura en capas (controlador–servicio–repositorio) con patrón **DTO**
- Documentación con **Swagger/OpenAPI** y despliegue containerizado con **Docker Compose**

`Java 21` `Spring Boot 3` `Spring Security` `JWT` `PostgreSQL` `Docker`

### 🗺️ [ODYXS](https://github.com/CarlosBecharaDev/ODYXS)
Aplicación web full stack de guía turística de Cartagena (+40 rutas).
- Panel de administración protegido con **Spring Security** y autenticación por roles
- CRUD completo para lugares, eventos y actividades, con **JPA/Hibernate** sobre MySQL/MariaDB
- Soporte multiidioma (ES/EN) y chatbot integrado

`Java 21` `Spring Boot 3` `Thymeleaf` `MySQL/MariaDB` `Docker`
